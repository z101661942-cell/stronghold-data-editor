# 示例数据（sample-data）

这里的 JSON 是**本仓库自己编的假数据**，用途只有一个：**没有游戏数据也能把编辑器点开、看看界面长什么样。**

- 不含任何游戏文本：所有名字与文案都是「示例…」，数值也是随手写的。
- 结构照真实数据格式写（同样的字段、同样的嵌套），所以编辑器会像对待真数据一样渲染它。
- 数据量是精简的：**2 条的盟约、2 名干员、2 条特质、2 件道具、2 张卡、4 条效果**，只够演示。

## 怎么用

```bash
node tools/editor-server.cjs --port 3001
# 浏览器打开 http://localhost:3001/ → 右上角「选择 data 目录」→ 选中本目录
```

也可以直接「导入 JSON」，把这里的文件拖进编辑器。

## 会看到两条「提醒」，这是正常的

校验页会提示：

```
盟约数量为 2（原版 23）
道具数量为 2（原版 115）
```

这是编辑器在提醒你「这不是完整数据集」——精简示例本来就只有几条。除此之外**应当 0 错误、0 提醒**（如果你看到别的报错，说明示例数据坏了，欢迎提 issue）。

## 文件对应关系

| 文件 | 内容 |
| --- | --- |
| `bonds.json` | 2 条盟约（甲 / 乙），成员指向示例干员 |
| `chess.json` | `sample_char_a` / `sample_char_b`（普通 / 精锐） |
| `garrisons.json` | `garrison_sample_a` / `_b` 两条特质 |
| `items.json` | `sample_item_1_01_a` / `_b` 两件装备 |
| `effects.json` | 4 条效果：1 条 EQUIP + 1 条 EQUIP（精锐版）+ 1 条 ENEMY_GAIN + 1 条 BUFF_GAIN |
| `choices.json` | 1 张悬赏卡 + 1 张战术卡（各自指向上面那条效果） |
| `backups.json` | 1 名自选六星（`sample_diy_char`），两处来源都给全 |

想拿它当「改自己数据」的模板也行：结构是对的，把 id 与文案换成你的即可。
